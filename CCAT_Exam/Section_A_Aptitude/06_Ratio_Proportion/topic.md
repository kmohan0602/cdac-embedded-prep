## Key Formulas

Ratio a:b = a/b

If a:b = x and b:c = y → a:b:c by making b equal in both

Proportion: a:b = c:d → a×d = b×c (cross multiply)

Average = Sum of items / Number of items

If average of N items is A and one item x is added:
New average = (N×A + x) / (N+1)

Weighted average = (w1×a1 + w2×a2) / (w1+w2)

## Sample Questions

Q1. Ratio of A:B = 3:4, B:C = 5:6. Find A:B:C.
Answer: A:B = 15:20, B:C = 20:24 → A:B:C = 15:20:24

Q2. Average of 5 numbers is 40. A 6th number 70 is added. New average?
Answer: (5×40 + 70)/6 = 270/6 = 45

Q3. Divide 120 in ratio 3:5.
Answer: 3 parts = 120×3/8 = 45, 5 parts = 75
