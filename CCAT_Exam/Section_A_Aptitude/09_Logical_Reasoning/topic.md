## Sub-topics and Practice Links

### Number Series
Pattern: Find the next number in series
Practice: https://www.indiabix.com/logical-reasoning/number-series/
Example: 2, 6, 12, 20, 30, ? → Answer: 42 (differences: 4,6,8,10,12)

### Letter Series
Practice: https://www.indiabix.com/logical-reasoning/letter-and-symbol-series/
Example: A, C, F, J, ? → Answer: O (gaps: +2, +3, +4, +5)

### Analogies
Practice: https://www.indiabix.com/logical-reasoning/analogies/
Example: Doctor : Hospital :: Teacher : ? → Answer: School

### Blood Relations
Practice: https://www.indiabix.com/logical-reasoning/blood-relation-test/
Tip: Draw a family tree diagram for each question

### Coding-Decoding
Practice: https://www.indiabix.com/logical-reasoning/verbal-classification/
Example: If CAT = 3120, then DOG = ?
→ C=3, A=1, T=20 → D=4, O=15, G=7 → Answer: 41507
