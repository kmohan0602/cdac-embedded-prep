## Key Formulas

If A finishes in N days → A's 1 day work = 1/N

If A and B together finish in x days:
1/x = 1/A + 1/B  →  x = (A×B)/(A+B)

If A does work in A days, B in B days, C in C days together:
1/T = 1/A + 1/B + 1/C

Work = Rate × Time

If A is twice as fast as B → A takes half the time of B

## Sample Questions

Q1. A does a work in 10 days, B in 15 days. Together?
Answer: T = (10×15)/(10+15) = 150/25 = 6 days

Q2. A and B together finish in 8 days. A alone in 12 days. B alone?
Answer: 1/B = 1/8 - 1/12 = 3/24 - 2/24 = 1/24 → B = 24 days

Q3. A is 3 times as fast as B. A takes 20 days less than B. Time together?
Answer: B = 3A → B - A = 20 → 3A - A = 20 → A = 10, B = 30
Together = (10×30)/40 = 7.5 days
