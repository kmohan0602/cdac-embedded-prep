## Key Formulas

Profit = SP - CP
Loss  = CP - SP

Profit% = (Profit / CP) × 100
Loss%   = (Loss / CP)   × 100

SP = CP × (1 + Profit%/100)
SP = CP × (1 - Loss%/100)

CP = SP / (1 + Profit%/100)
CP = SP / (1 - Loss%/100)

Discount = Marked Price - Selling Price
Discount% = (Discount / Marked Price) × 100

## Sample Questions

Q1. CP = 500, SP = 600. Profit%?
Answer: (100/500) × 100 = 20%

Q2. A shopkeeper marks price 25% above CP, then gives 10% discount. Profit%?
Answer: SP = CP × 1.25 × 0.90 = CP × 1.125 → Profit = 12.5%

Q3. SP = 840, Loss% = 16%. Find CP.
Answer: CP = 840 / (1 - 0.16) = 840 / 0.84 = 1000
