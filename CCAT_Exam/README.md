# CCAT Exam — Complete Overview

## Exam Pattern

| Section | Name | Topics | Focus |
|---------|------|--------|-------|
| A | Aptitude | Quantitative + Logical Reasoning + Verbal | General intelligence |
| B | CS Core | C, Data Structures, OS, DBMS, CN | CS fundamentals |
| C | Specialization | Electronics + Embedded (for DESD track) | Domain specific |

## Duration
- ~2 hours total
- Each section timed separately (verify on admit card)

## Marking
- +1 for correct
- -0.25 for wrong (negative marking — don't guess blindly)
