## STEP 9: Bitwise Operations — CRITICAL FOR EMBEDDED
Read these in order:

32. Bitwise Operators (&, |, ^, ~, <<, >>)
    https://www.geeksforgeeks.org/c/bitwise-operators-in-c-cpp/

    Memorize these 4 patterns:
    Set bit n:    reg |= (1 << n)
    Clear bit n:  reg &= ~(1 << n)
    Toggle bit n: reg ^= (1 << n)
    Check bit n:  reg & (1 << n)
